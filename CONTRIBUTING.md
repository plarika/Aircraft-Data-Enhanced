# Contributing

Do not commit SDK binaries, captures, decoded communications, databases,
personal paths or logs. Use synthetic fixtures, preserve SPDX headers, run the
public audit and keep blocking work outside the IQ callback. New original code
is MIT; changes to `ReedSolomon255249.cs` are LGPL-2.1-or-later. Contributors
must identify third-party sources and have the right to submit their work.
