# SDR# SDK references — not included

1. Open https://airspy.com/download/
2. Locate **SDR# SDK for Plugin Developers**.
3. Extract the official SDK.
4. Copy `SDRSharp.Common.dll` and `SDRSharp.Radio.dll` into this directory.

Do not commit or redistribute the SDK DLLs from this repository. Their terms
remain those supplied by Airspy.
